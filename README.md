# CineFlow Extensions

Official extension repository for **CineFlow**, providing content providers for movies, series, and anime.

---

## Repository URL

To add this repository to CineFlow (pre-installed by default in CineFlow):

```
https://raw.githubusercontent.com/jahru23/cineflow-extensions/builds/repo.json
```

---

## Included Providers

### Movies & Series
* **LK21** (Film & Series Indonesia)
* **Idlix** (Film & Series Sub Indo)
* **Rebahin** (Streaming Film Box Office)
* **MovieBox** (Cinema & TV Shows)
* **BlurayUFR** (Koleksi Film HD)
* **Pahe** (Mini-size HD Movies)

### Anime & Donghua
* **Anichin** (Donghua Sub Indo)
* **Kuramanime** (Anime Sub Indo)
* **Otakudesu** (Anime Sub Indo)
* **Donghub** (Donghua)
* **Oploverz** (Anime Ongoing)
* **Nimegami** (Batch & Ongoing Anime)
* **Kuronime** (Anime)
* **Sokuja** (Anime & Tokusatsu)
* **Animasu** (Anime)
* **AnimeIndo** (Anime)

### Adult / 18+ (Manual Install)
* **Hanime**
* **Nekopoi**
* **SemiRebahin**

---

## Build Commands

```bash
./gradlew make makePluginsJson
```

Compiled `.cs3` files are generated in `build/` and deployed to the `builds` branch.
